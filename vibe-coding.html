01 / Entender

Vos decidís qué problema resolver.

IDEA

Describí una necesidad

¿Quién va a usar la herramienta? ¿Qué necesita hacer? Por ejemplo: organizar los materiales para una maqueta.

CONVERSACIÓN

Pedí una primera versión

La IA escribe código a partir de tus instrucciones. Empezá por algo pequeño y agregá funciones de a una.

PRUEBA

Revisá y mejorá

Usá el resultado, buscá errores y explicá qué debe cambiar. Que se vea bien no significa que funcione bien.

La IA también se equivoca. Vos seguís siendo responsable de revisar el resultado. Comprender el código y aprender programación ayuda a construir con más criterio.

02 / Dar instrucciones

Una buena consigna cambia el resultado.

“Haceme una página para la escuela.”

Faltan el destinatario, el objetivo y las funciones. La IA tendrá que completar esos vacíos con suposiciones.

Comparación didáctica preparada: esta página no se conecta a una IA ni genera código.

03 / Ubicar cada pieza

Tres palabras que vas a escuchar.

Código

Las instrucciones que definen cómo se ve y cómo funciona una aplicación.

Repositorio · GitHub

Los archivos del proyecto con un historial de cambios. Permite colaborar y recuperar versiones anteriores.

Hosting

El servicio que publica y mantiene disponible el sitio en internet. GitHub Pages puede alojar páginas estáticas.

Guardar el código no equivale a guardar los datos de una aplicación. Los pedidos, las cuentas y los archivos de usuarios necesitan su propio sistema de almacenamiento.

04 / Llevarlo al aula

Desafío: una lista para la maqueta.

Objetivo: diseñar una herramienta sencilla para organizar materiales de un trabajo escolar.

  1. Definí quién la usa y qué necesita.
  2. Pedí una página con material, cantidad y casilla de “conseguido”.
  3. Probá agregar, marcar y borrar un material. Revisá qué pasa al recargar.
  4. Mejorá una función y comprobá que las anteriores sigan funcionando.
  5. Contá qué pediste, qué falló y cómo lo resolviste.

Una consigna para comenzar

05 / Trabajar con criterio

Antes de darlo por terminado…

Probalo de verdad

Ingresá cantidades vacías, textos largos y datos incorrectos. Revisá el celular y la computadora.

Cuidá la información

Para practicar, usá datos ficticios. No pegues contraseñas, claves de API ni datos personales de compañeros.

Explicá lo aprendido

Registrá las instrucciones, las correcciones y los límites. Citá las fuentes y contá cómo usaste la IA.

06 / Una propuesta para el CET

Programación y creación de proyectos con inteligencia artificial

Una posible materia para aprender a resolver problemas mediante proyectos concretos. El vibe coding sería una forma de trabajar dentro de ella, acompañada por bases de programación, comprensión del código y revisión de los resultados.

01 / NECESIDAD

Detectar un problema

Reconocer qué se quiere resolver, para quién y qué resultado sería útil.

02 / CONTEXTO

Conocer antes de pedir

Reunir información sobre los usuarios, los recursos disponibles y las limitaciones. Lo que sabemos del problema nos permite comunicarnos mejor con la IA.

03 / INSTRUCCIONES

Explicar lo que necesitamos

Escribir un prompt —una instrucción para la IA— con un objetivo claro, contexto y condiciones. Preguntar, aclarar y ajustar forma parte del trabajo.

04 / COMPRENSIÓN

Entender lo que construimos

Aprender bases de programación: variables, condiciones, repeticiones y funciones. Poder explicar cómo funciona el proyecto, aunque la IA escriba parte del código.

05 / PRUEBAS

Probar y corregir

Comprobar cada función, reconocer errores, registrar las pruebas y verificar que las mejoras no rompan lo que ya funcionaba.

06 / RESPONSABILIDAD

Cuidar nuestras decisiones

Proteger datos personales, respetar la autoría, reconocer el uso de IA y revisar la seguridad del proyecto.

El contexto es clave. Para un riego con Arduino, primero hay que explicar qué se quiere regar, con qué agua se cuenta, qué componentes están disponibles y cuándo debería funcionar. El diálogo con la IA permite aclarar y revisar esas decisiones: una convivencia de trabajo que también se aprende.

Proyectos que unen áreas del CET

Trabajos del taller

Una página para recibir y organizar trabajos. Vincula programación, comunicación y necesidades del taller.

Registro de materiales

Una herramienta para registrar cantidades, entradas y salidas. Vincula programación, materiales y organización.

Riego con Arduino

Un sistema que responda a condiciones definidas. Vincula programación, electrónica y automatización, comenzando con una simulación y pruebas supervisadas.

¿Cómo se evaluaría?

El alumno debería poder explicar sus decisiones, mostrar las pruebas realizadas, reconocer los límites y modificar su proyecto.

Consigna de evaluación: “Ahora cambiá una condición del problema y adaptá tu proyecto”.

Conseguir que aparezca una página sería apenas el comienzo. El aprendizaje se demuestra al comprenderla, probarla y poder mejorarla.
